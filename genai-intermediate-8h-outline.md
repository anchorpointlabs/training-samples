# GenAI intermediate: 8 h outline

For staff who use the basics and want the output to stop looking generic. By the end they can run a real, recurring work process with an AI reliably.

| Block | Time | What happens |
|---|---|---|
| 1. Why the output is generic | 60 min | Context: what the model knows about your company (nothing). Demo: the same prompt with and without context. |
| 2. Building the context | 90 min | Anchor Files: identity, products, brand, audience. Learners draft their team's context file. |
| 3. Reusable prompts | 90 min | Turning one-off prompts into saved, shared templates with variables. |
| 4. Multi-step work | 90 min | Breaking a recurring deliverable into steps. Which steps the AI runs alone, which it drafts, which stay human. |
| 5. Voice and consistency | 60 min | Teaching the AI the company's writing rules. The forbidden-words list, tested. |
| 6. Evaluation loops | 60 min | Defining what "good" means for the output before prompting, and checking against it. |
| 7. Capstone | 30 min | Each learner ships one saved template that another team can use. |
