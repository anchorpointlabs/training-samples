# Copilot — sample exercise: turn a meeting thread into a task list

## The task

Take a real (or practice) Teams meeting recap and turn it into a clean task list with owners, using Copilot inside Teams or Word.

## The exercise (30 min)

1. Open the meeting recap for a meeting that actually happened (or the provided practice recap).
2. Ask Copilot:

> List every action item from this meeting. For each: the task, the owner as named in the meeting, the due date if one was given, and the sentence from the transcript that supports it. If an action has no owner or no date, say so — do not invent one.

3. Check the output line by line:
   - Every owner and date comes from the transcript.
   - Missing fields are marked, not guessed.
   - No task was added that was not discussed.
4. Fix the list by hand. Then ask Copilot to format the corrected list as a table for the team chat.

## What this proves

- Copilot is a first pass, not the final record.
- The check is where the skill lives: the user who skips step 3 ships a wrong task list with confidence.
