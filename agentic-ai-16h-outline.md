# Agentic AI — 16 h outline

Two days. For staff who will work alongside agents, not just chat windows. By the end they can brief an agent, check its work, and spot where an agent belongs — and where it does not.

## Day 1 — What agents are

| Block | Time | What happens |
|---|---|---|
| 1. From chat to agent | 90 min | What changes when the AI can act: tools, loops, autonomy. Live walkthrough of one agent run. |
| 2. The brief | 120 min | Writing a brief an agent can execute: goal, inputs, format, stop conditions. The difference between a brief and a prompt. |
| 3. Steering and checkpoints | 90 min | Where the human stays in the loop. Checkpoint design on a real workflow. |
| 4. Failure modes | 90 min | Hallucination, drift, loops, overreach. Reading the log of a failed agent run and finding where it went wrong. |
| 5. Hands-on: brief and run | 90 min | Each learner briefs an agent on a bounded task and runs it, twice. |

## Day 2 — Agents in your company

| Block | Time | What happens |
|---|---|---|
| 6. Mapping the work | 120 min | Which of the company's processes are agent-ready: repetitive, checkable, well-documented. Which are not. |
| 7. SOPs an agent can follow | 120 min | Rewriting one real SOP so an agent can execute it. The before/after test. |
| 8. Skills and knowledge files | 120 min | The agent's context: skills files, Anchor Files, the company's knowledge layer. |
| 9. Governance | 90 min | Permissions, approvals, audit trail. Who owns the agent's output. |
| 10. Capstone | 90 min | Teams build one working agent brief + SOP pair for a real process and present it. |
