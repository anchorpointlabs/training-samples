# GenAI intermediate: sample exercise: build your team's context file

## The task

A learner drafts the first version of their team's Anchor File (context file): who the team is, what it does, how it writes, what it never says.

## The exercise (40 min)

1. Gather the raw material: the team's mandate, two recent documents the team is proud of, and the list of things the team is tired of correcting.
2. Write the prompt:

> You are building a context file that a new AI assistant will read before helping my team. From the material below, extract:
>
> 1. Identity: who we are and what we do, in two sentences.
> 2. Products and scope: what we deliver, what we do not.
> 3. Voice rules: how we write, with three examples of phrases we use and three we never use.
> 4. Non-negotiables: anything we must never say or claim.
>
> Material:
> [paste the documents]
>
> Write the output as a markdown file with those four sections. Do not invent anything that is not in the material.

3. Read the draft critically. This file will speak for the team. Edit anything wrong, add anything missing.
4. Test it: start a fresh chat, paste the context file, and ask the AI to write a short team announcement. Does it sound like the team?

## What this proves

- Context is what separates generic output from company output.
- The context file is never finished: it gets better every time someone corrects it.
